# MediHub

MediHub is a modern healthcare appointment management system that connects patients and doctors through a secure and user-friendly platform. It streamlines appointment scheduling, consultation management, and patient interactions while providing role-based access for Patients, Doctors, and Administrators.


**FEATURES**

• Secure Authentication with separate login for Patients, Doctors, and Admin.
• Appointment Booking and Management.
• Doctor Dashboard for approving and managing appointments.
• Patient Dashboard for booking and tracking appointments.
• Profile Management.
• Forgot Password with OTP Verification.
• Feedback and Rating System.
• Responsive and User-Friendly Interface.
• Role-Based Access Control.

INSTALLATION
------------------------------------------------------------

1. Clone the repository

git clone https://github.com/your-username/MediHub.git

2. Navigate to the project

cd MediHub

3. Install frontend dependencies

cd frontend
npm install
ng serve

4. Install backend dependencies

cd ../backend
npm install
npm start
